# My Neovim Configuration 
this is my daily neovim configuration

## Installation

### Requirements
- Neovim >= 0.10.0

### Installation
1.  Clone this repository

```bash
git clone https://github.com/mohamad-supangat/nvim.git ~/.config/nvim
```

2. Run neovim

```bash
nvim
```
